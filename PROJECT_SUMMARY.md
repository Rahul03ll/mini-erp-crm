## ✅ Completed Features

1. **Authentication & Roles** - JWT, 4 roles, RBAC
2. **Customer CRM** - CRUD, search, follow-up notes
3. **Product & Inventory** - Stock movement log, low-stock alerts
4. **Sales Challan** - Draft/Confirm workflow, atomic stock validation
5. **Invoice PDF Export** - Download invoices for confirmed challans

**Backend:** Node.js, TypeScript, Express, Prisma, PostgreSQL  
**Frontend:** React, TypeScript, Vite, Tailwind CSS  
**Deployment:** Render (backend), Vercel (frontend), Neon (database)
